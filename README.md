# Passenger Car Repair Guides (MY2020+)

Brand-by-brand repair guides for passenger cars manufactured from **2020 onward** in **Japan**, the **United States**, and **China**.

Each brand file has **25–35** field examples with symptoms, diagnosis steps, and repair procedures. Hybrid (HEV/PHEV/EREV) and battery-electric (BEV) systems are covered in depth.

A single index of those cases and their repairs is in [malfunction-cases-2020-plus.md](malfunction-cases-2020-plus.md).

Great Wall and Hongqi compiled: [china-great-wall-hongqi.md](china-great-wall-hongqi.md).

HEV / BEV troubleshooting methods by brand and model: [hev-bev-troubleshooting.md](hev-bev-troubleshooting.md).

OBD-II / DLC connector by brand and model: [obd2-connectors.md](obd2-connectors.md).

## Safety reminder

Orange HV circuits require OEM lockout, Class 0 PPE, and isolation verification before service. This material is a technician field aid—always confirm against VIN-specific OEM service information, TSBs, and recalls.
